# C# Preferences

Apply this skill whenever generating, changing, answering questions about, or reviewing C# code.

## Coding workflow

1. Inspect `.editorconfig` and existing project conventions first. `.editorconfig` takes precedence over every C# style rule in this skill.
2. Read [references/csharp-preferences.md](references/csharp-preferences.md) before generating, modifying, or reviewing C# code.
3. Validate any proposed non-Microsoft dependency before implementation.
4. Preserve clear separation between models, mapping, API composition, and injected services.
